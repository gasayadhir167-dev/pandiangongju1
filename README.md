# 现场盘点助手 v2.0.0

医疗设备现场盘点工具。项目制、离线可用、数据和照片都存在手机本机。

- 一个医院 = 一个项目，上传一次设备清单（xlsx / xls / csv）就能一直用
- 顶部常驻搜索栏：资产编码 / SN / 型号 / 名称 / 品牌
- 一键四态：有 / 没有 / 异常 / 待确认，带撤销，确认后不会跳回列表顶部
- 大类 → 名称型号 → 具体设备三级差额核对，支持按数量核销
- 拍照（整体照 + 铭牌照）自动存进当前项目，带模糊 / 曝光检查
- 现场新增、现场速记、收尾核对
- 导出 xlsx（盘点结果 + 现场速记两张表），平时不用导

没有服务器、没有账号、没有云端。所有数据只在你手机的浏览器存储里。

---

## 文件清单

| 文件 | 作用 |
|---|---|
| `index.html` | App 本体，单文件，xlsx 解析库已内嵌 |
| `manifest.webmanifest` | 让安卓可以「安装」成 App（图标、启动方式） |
| `sw.js` | Service Worker，断网也能打开 |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | 应用图标 |

六个文件必须放在**同一个目录**下，缺一个都会影响安装或离线。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，例如 `inventory-app`，**Public**（Pages 免费版要求公开仓库）。
2. 仓库页面 → `Add file` → `Upload files` → 把上面六个文件一起拖进去 → `Commit changes`。
3. `Settings` → 左侧 `Pages` → Source 选 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)` → Save。
4. 等 1～2 分钟，页面顶部会出现网址：

   ```
   https://<你的用户名>.github.io/inventory-app/
   ```

5. 手机 Chrome 打开这个网址。

> 仓库是公开的，意味着**程序代码**任何人都能看到。但你的设备清单、盘点数据、照片从来不会上传，只在手机本地，别人看不到。

## 装到手机主屏（安卓）

Chrome 打开网址 → 右上角 `⋮` → **添加到主屏幕** / **安装应用**。

装好以后：

- 主屏有独立图标，打开是全屏，没有地址栏
- 断网、医院信号差、飞行模式都能正常盘点拍照
- 关掉重开自动回到上次的项目

## 更新版本

改完 `index.html` 之后：

1. 把 `sw.js` 里的 `const VERSION = 'v2.0.0'` 改成新的（例如 `v2.0.1'`）
2. 两个文件一起上传覆盖
3. 手机上把 App 关掉再打开两次（第一次后台下载新版，第二次生效）

不改 VERSION 的话，手机可能一直用旧缓存。

## 重要：数据是按「网址」隔离的

浏览器存储绑定在域名上，所以：

- 之前用**本地文件**（`file://`）打开时存的项目，在 GitHub Pages 网址上**看不到**
- 换一个网址（换仓库名、换用户名）也一样看不到

从旧的地方搬过来：旧环境里打开「项目资料 → 数据导出 → 导出任务包」，得到一个 `.json`，在新网址的欢迎页「从备份恢复」导进去。**注意：任务包不含照片**，照片要用「回传到电脑（局域网）」或「另存到系统相册」单独带走。

一开始就用 Pages 网址的话，不存在这个问题。

## 关于数据安全

- 项目数据和照片存在 IndexedDB，App 启动时会申请持久化存储（`navigator.storage.persist()`），设置 → 关于里能看到是否开启成功
- 极端情况（手机存储空间快满、手动清理浏览器数据、卸载 Chrome）浏览器仍可能清掉。重要项目盘完后导一份任务包留底
- 别用无痕模式，无痕模式关掉就没了

## 已知限制

- iOS Safari 对这类本地存储限制更多，建议用**安卓 Chrome**
- 「回传到电脑（局域网）」是 https 页面访问 http 局域网地址，Chrome 可能拦截混合内容。如果被拦，用局域网 http 地址打开 App，或者直接把照片「另存到系统相册」
- 长按型号搜设备图片需要联网，其余功能全部离线可用
